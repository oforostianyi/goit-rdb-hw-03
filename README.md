# Домашня робота №3. Bank Marketing

Розглянемо [Bank Marketing з UCI](https://archive.ics.uci.edu/dataset/222/bank+marketing) — дані про телефонні кампанії португальського банку та оформлення депозитів.

[Відкрити notebook у Google Colab](https://colab.research.google.com/github/oforostianyi/goit-rdb-hw-03/blob/main/goit-rdb-hw-03.ipynb)

## Дані

Візьмемо повний `bank-full.csv`: **45 211 рядків**, 16 ознак і цільова колонка `y`. Використаємо всі записи з [офіційного архіву UCI](https://archive.ics.uci.edu/static/public/222/bank+marketing.zip), без додаткового відбору.

Вихідний CSV є у `data/`: UTF-8, роздільник `;`, розмір 4 610 348 байтів. Код отримання файла знайдемо в notebook.

Автори датасету: S. Moro, P. Rita, P. Cortez (2014). DOI: [10.24432/C5K306](https://doi.org/10.24432/C5K306). Ліцензія: **CC BY 4.0**.

## Запуск у Colab

1. Відкриємо notebook за посиланням вище.
2. Залишимо стандартне середовище **Python 3 / CPU**.
3. Оберемо **«Середовище виконання → Виконати всі»**.
4. Для перевірки повторного запуску скористаємося **«Перезапустити сеанс і виконати всі клітинки»**.

Залежності встановимо першою клітинкою. Запустимо PostgreSQL через `pgserver`, а за його відсутності — через `apt`. Дані завантажимо кодом із UCI.

## Що розглянемо

Завантажимо CSV через `COPY FROM STDIN` у `hw3_bank_staging` з текстовими полями. Через `INSERT INTO ... SELECT` перенесемо дані в типізовану `hw3_bank_clean`.

Перетворимо `yes/no` на `BOOLEAN`, категорії `unknown` — на `NULL`. Для балансу використаємо `NUMERIC(12,2)`, а `pdays = -1` врахуємо як відсутність попереднього контакту.

Порівняємо кількість рядків, перевіримо дублікати й пропуски, проаналізуємо професії та баланс. Розглянемо десять бізнес-питань через SQL і сформулюємо висновки. У Reflection обговоримо вибір ознак та ризики витоку інформації.
